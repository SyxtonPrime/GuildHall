# New enemy sprites (pass 4)

Seventeen extra enemies drawn in the same 16×16 / 24×24 pixel style as the live roster. **All 17 are now wired into the game (v23)** with their own mechanics — see the design notes; the ideas below were the original placeholders. Preview them in the sprite gallery artifact (https://claude.ai/artifact/AJCyHxvrRcsr9rz7nzBKcE, section "New enemies"). Enemies face the viewer with a slight turn to the left; one character = one pixel, `.` = transparent; letters map to the palette below (same `SPR_PAL` as in the game).

**Behaviour ideas are placeholders only** — nothing here is designed or balanced.

## How to wire one in
1. Add its grid to `SPR` in the game's `ui` script (same format as the existing entries): `newid:["row0","row1",…]`.
2. Add an `ENEMIES` entry with `name`, `row`, `hp`, `atk`, `spd`, optional `armor/crit/dodge/apply/ab/hooks` (and `elite:true` / `boss:true`).
3. Add the id to the right `POOLS[act]` (or `ELITES` / `BOSSES`). Sprites are looked up by enemy id, so nothing else changes.
