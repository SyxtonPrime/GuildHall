Guildhall Sprites

18 heroes and 17 enemies as 16×16 pixel sprites (elites and bosses at 24×24), all on one 30-color palette that matches the game UI. Everyone faces the viewer with a slight turn: heroes to the right, enemies to the left. Static for now; each is drawn on a shared frame so idle and attack poses can be added later.
